This repository contains my data analytics internship projects completed during the Decodelabs Data Analytics program. The projects demonstrate my skills in data cleaning, descriptive statistics and interactive PowerBi dashboards development for sales analysis.
Projects Include:
* Data Cleaning: cleaned and transformed raw sales data for analysis
* Descriptive Statistics: Calculated measures such as mean, median, mode,standard deviation, minimum, maximum, sum count and range
* PowerBi: Built an interactive business dashboard featuring revenue trends, product performance, Payment methods and referral source analysis
* Tools used: Microsoft excel, Power Query, Microsoft PowerBi
